## 🔭 Обзор

### Что это делает

Карта в The Blood of Dawnwalker хорошая, но на ней нет большей части коллекционных предметов и
мест, найденных сообществом. Этот мод берёт 1799 таких меток (79 категорий, от святилищ и
лагерей до руководств, книг и сундуков) и рисует их на карте самой игры, той, что открывается
по M.

Можно навести курсор на метку и прочитать название, отметить её выполненной левым кликом,
скрыть целые категории, а выполненные сделать бледными или убрать. Всё сохраняется в папке мода.

Это Lua-мод для UE4SS. Нет программы, которую нужно запускать, и ничего не нужно ставить,
кроме UE4SS.

### Как это работает

1. Когда игра загружает мод, он читает `Data\markers.txt` (категории и мировые координаты),
   `progress.txt` и `settings.txt`.
2. При открытии карты он добавляет один слой в контейнер меток самой карты и ставит каждую метку
   встроенной функцией игры, переводящей мир в карту, по 60 меток за кадр (около половины
   секунды на все).
3. При масштабировании меняется только масштаб слоя, поэтому метки остаются привязанными к карте.
   Когда масштаб устоялся, значки подгоняются под размер меток игры, которые мод измеряет на карте.
4. Какой значок под курсором, сообщает система интерфейса игры. Так наведение и клики находят
   нужную метку без экранных вычислений.
5. Клики и изменения фильтров обрабатываются по одному в игровом потоке. Текущий шаг пишется
   в `guard.txt`, чтобы при следующем запуске можно было отследить вылет.

```
markers.txt ──> открыта карта (M) ──> один слой в контейнере меток карты
                                       ├─ 1799 значков, размещены через WorldToMapPosition
                                       ├─ масштаб: только масштаб слоя
                                       └─ наведение / клик: интерфейс игры сообщает, какой значок
progress.txt <── левый клик по метке, правый клик по категории
settings.txt <── панель фильтров
```

### Структура файлов

| Путь | Что там |
|---|---|
| `ValeSangoraMap\enabled.txt` | Говорит UE4SS загрузить мод. Пустой файл. |
| `ValeSangoraMap\Scripts\main.lua` | Весь мод |
| `ValeSangoraMap\Data\markers.txt` | Категории и 1799 меток с мировыми координатами |
| `ValeSangoraMap\Icons\*.png` | По значку на каждую категорию и группу |
| `ValeSangoraMap\progress.txt` | Пишет мод: ваши выполненные метки |
| `ValeSangoraMap\settings.txt` | Пишет мод: ваш выбор в панели |
| `ValeSangoraMap\vsm.log` | Пишет мод: что произошло, для сообщений об ошибках |
| `ValeSangoraMap\guard.txt` | Пишет мод: текущий шаг |

В этом репозитории папка мода находится в `src\ValeSangoraMap`.

## 📦 Установка

### Требования

| Требование | Зачем |
|---|---|
| The Blood of Dawnwalker (PC) | Мод рисует на её экране карты |
| UE4SS 3.0.1 или новее, работающий с игрой | Загружает Lua-моды в игру; без него ничего не работает |
| Windows 10 или 11 | Игра и UE4SS работают в Windows |

### Пошагово

1. Найдите папку игры: в Steam правый клик по игре, **Управление**,
   **Просмотреть локальные файлы**.
2. Откройте `Dawnwalker\Binaries\Win64`. Если папки `ue4ss` нет, скачайте `UE4SS_v3.0.1.zip`
   (не `zDEV`) со [страницы релизов UE4SS](https://github.com/UE4SS-RE/RE-UE4SS/releases) и
   скопируйте всё его содержимое в `Win64`.
3. Скачайте `ValeSangoraMap-1.0.0.zip` со
   [страницы релизов](https://github.com/Miabeyefendi/ValeSangora-InGameMap/releases/latest).
4. Скопируйте папку `ValeSangoraMap` из zip в `Dawnwalker\Binaries\Win64\ue4ss\Mods`.
5. Запустите игру, загрузите сохранение, нажмите **M**.

### Проверка установки

После запуска игры откройте `ue4ss\Mods\ValeSangoraMap\vsm.log`. В нём есть:

```
loaded 79 categories, 1799 markers
ready, open the M map
```

После первого открытия карты появятся строки:

```
layer created at zoom ..., building 1799 markers
all markers built
```

### Обновление

Скопируйте новую папку `ValeSangoraMap` поверх старой и разрешите Windows заменить файлы.
`progress.txt` и `settings.txt` нет в zip, поэтому прогресс и выбор сохраняются.

### Удаление

Удалите `ue4ss\Mods\ValeSangoraMap`. Мод больше ничего нигде не пишет и никогда не трогает
ваше сохранение.

### Панель фильтров

В левом верхнем углу экрана карты. Кликните по заголовку, чтобы свернуть.

| Элемент | Что делает |
|---|---|
| `Progress` | Выполнено / всего меток, с зелёной полосой |
| `Markers: Hide / Show` | Скрыть или показать все категории сразу |
| `Show: All / Finished / Ongoing` | Все, только выполненные или только оставшиеся |
| `Finished markers: Faded / Hidden` | При Show = All: выполненные бледные или не рисуются |
| `Icon size: + / -` | Размер меток с шагом 5%, от 50% до 200% |
| Строка группы, левый клик | Показать или скрыть всю группу |
| Строка группы, правый клик | Отметить всю группу выполненной, повторный правый клик отменяет |
| `>` в строке группы | Открыть её категории ниже (одна группа за раз) |
| Строка категории, левый / правый клик | То же, что для группы, для одной категории |
| `d / t` справа | Выполнено (зелёным) / всего (красным) в строке, всё зелёное при завершении |

### Блок подсказок

Под панелью. Короткий список действий мыши, чтобы ничего не запоминать.

### На карте

| Элемент | Что делает |
|---|---|
| Навести на метку | Рядом её название и категория |
| Левый клик по метке | Отметить выполненной, повторный левый клик отменяет |
| Правый клик | Путевая точка самой игры, без изменений |
| Перетаскивание, колесо | Двигать и масштабировать карту как обычно; метки следуют |

## 🧩 Справочник возможностей

### Метки на карте игры

**Что делает.** Рисует 1799 меток сообщества на карте по клавише M.

**Как работает.** В контейнер меток карты добавляется один слой. Позиции берутся из встроенной
функции игры, переводящей мир в карту, поэтому они совпадают с метками игры. Построение занимает
около половины секунды (60 меток за кадр). Масштабирование меняет только масштаб слоя.

**Как пользоваться.** Откройте карту. Больше ничего.

**Границы.** Позиции взяты с карты сообщества, некоторые могут смещаться на несколько метров.

---

### Название при наведении

**Что делает.** Показывает название и категорию метки под курсором.

**Как работает.** Система интерфейса игры сообщает, какой значок под курсором. Пока мышь или карта двигаются, мод
проверяет по 150 значков за кадр, пока не найдёт нужный. Когда ничего не движется,
он не делает никакой работы.

**Как пользоваться.** Наведите курсор на метку.

**Границы.** У скрытых меток названия нет.

---

### Отметить выполненным

**Что делает.** Левый клик переключает метку между выполненной и невыполненной.

**Как работает.** Клик ждёт 0,25 секунды. Если за это время карта сдвинулась или
масштабировалась, это было перетаскивание, и ничего не отмечается. Номер метки пишется в
`progress.txt`.

**Как пользоваться.** Левый клик по метке. Повторный левый клик отменяет.

**Границы.** Мод не читает, что вы сделали в игре. Отмечаете вы сами.

---

### Отметить всю категорию

**Что делает.** Правый клик по группе или категории в панели: все её метки выполнены.

**Как работает.** Если что-то ещё не выполнено, выполненным становится всё. Если всё уже
выполнено, всё становится невыполненным.

**Как пользоваться.** Правый клик по строке. Повторный правый клик отменяет.

**Границы.** Отмена очищает все метки строки, в том числе отмеченные по одной.

---

### Фильтры

**Что делает.** Показывает или скрывает группы и категории, выбирает Все, Выполненные или
Оставшиеся.

**Как работает.** Изменения применяются к 300 значкам за кадр, так что даже 1799 изменений
занимают несколько кадров. Выбор сохраняется в `settings.txt`.

**Как пользоваться.** Левый клик по строкам и кнопкам панели.

**Границы.** Поля поиска пока нет.

---

### Выполненные метки: бледные или скрытые

**Что делает.** При Show = All выполненные метки рисуются с непрозрачностью 30% (Faded) или не
рисуются (Hidden).

**Как работает.** Hidden работает как Ongoing: выполненные не рисуются и не показывают название.

**Как пользоваться.** Нажмите Faded или Hidden в панели.

**Границы.** При Show = Finished выполненные всегда видны полностью.

---

### Размер значков

**Что делает.** Делает метки крупнее или мельче.

**Как работает.** Базовый размер равен размеру меток самой игры, измеренному на карте после
каждого масштабирования. Настройка панели его умножает.

**Как пользоваться.** Нажмите + или - в строке Icon size.

**Границы.** От 50% до 200%.

---

### Защита от вылетов

**Что делает.** Не даёт проблеме в моде накапливаться и сообщает, где она была.

**Как работает.** Ошибки Lua перехватываются; 10 ошибок за 10 секунд ставят мод на паузу на 30
секунд. Каждый тяжёлый шаг пишет своё имя в `guard.txt`, а по завершении `idle`. Если игра
закрылась посреди шага, следующий запуск записывает `previous session ended during: <шаг>` и
проводит эту сессию меньшими порциями и с более медленными кликами. При загрузке сохранения или
уровня мод отпускает все ссылки на старую карту до её уничтожения.

**Как пользоваться.** Ничего делать не нужно. Если что-то пошло не так, прочитайте `vsm.log`.

**Границы.** Вылет внутри самой игры или UE4SS перехватить нельзя, только отследить.

## ⚙️ Справочник настроек

Каждая настройка, что она принимает и что происходит при изменении.

### settings.txt

Одна настройка на строку, ключ и значение разделены табуляцией. Файл пишет панель; править его
вручную не нужно.

| Ключ | Тип | По умолчанию | Эффект |
|---|---|---|---|
| `done` | `all`, `finished`, `ongoing` | `all` | Строка Show |
| `style` | `faded`, `hidden` | `faded` | Строка Finished markers |
| `size` | число от `0.50` до `2.00` | `1.00` | Строка Icon size |
| `offcat` | ключ категории | нет | По строке на каждую скрытую категорию |

### progress.txt

| Ключ | Тип | По умолчанию | Эффект |
|---|---|---|---|
| по строке на метку | номер метки | пусто | Эта метка считается выполненной |

### Где хранятся настройки

Оба файла лежат в папке мода, `ue4ss\Mods\ValeSangoraMap`. Это обычный текст. Правьте их только
при закрытой игре, мод пишет их во время работы. Для сохранности прогресса делайте копию
`progress.txt`. Ни один из файлов не содержит данных учётных записей.

## 🔧 Устранение неполадок

### Нажимаю M, а меток нет

**Причина.** Мод не загружен или сохранение ещё не загружено.
**Решение.** Проверьте, что существует `ue4ss\Mods\ValeSangoraMap\enabled.txt` и что в `vsm.log`
есть `ready, open the M map`. Загрузите сохранение; в главном меню карты нет.

### Не работает ни один мод

**Причина.** UE4SS не запущен.
**Решение.** Установите UE4SS заново (Установка, шаг 2). Когда он работает, появляется
`ue4ss\UE4SS.log`.

### Метки слишком крупные или мелкие

**Причина.** Размер экрана и вкус.
**Решение.** Используйте Icon size + / - в панели.

### Клик по метке ничего не делает

**Причина.** Во время клика карта сдвинулась (перетаскивание), или клик пришёл сразу после
предыдущего.
**Решение.** Кликайте, не двигая мышь. Принимается не более пяти кликов в секунду.

### Сбор логов для отчёта об ошибке

Пришлите `ue4ss\Mods\ValeSangoraMap\vsm.log`, а если игра закрылась, то и первые строки
`vsm.log` следующего запуска. Пригодятся и последние строки `ue4ss\UE4SS.log`. В этих файлах нет
данных учётных записей, но проверьте их перед публикацией.

## ❓ Частые вопросы

**Мод меняет моё сохранение?**
Нет. Мод только рисует на экране карты. Прогресс хранится в `progress.txt`.

**Можно ли использовать его вместе с Vale Sangora Live Map?**
Да. Они независимы, и их файлы прогресса тоже.

**Можно ли добавить свои метки?**
Добавьте строки в `Data\markers.txt` в том же формате (ключ категории, мировой X, мировой Y,
уникальный номер, название, через табуляцию). Обновление заменяет этот файл.
